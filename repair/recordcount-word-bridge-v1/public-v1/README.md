# RECORDCOUNT source-state, word, and primitive x86 bridge

This addendum contains 36 closed declarations relating the retained eight-instruction RECORDCOUNT controller to the original Grok signed/unsigned 64-bit models and preserved CX4 native primitive semantics. Its successful receipts record 22 freshly compiled modules, one additional freshly compiled type-only module, and a recursive kernel check explicitly targeting all 23 modules. All selected declarations are closed under the global context; the kernel reports no axioms, unsafe fixpoints, type-in-type dependencies, or assumed positivity.

`Proof/PmpWordSub.v` proves the actual C2 subtraction update and both retained RECORDCOUNT execution prefixes, their exact unsigned encodings, bounded decoding, the source negative test, and encoded return/FAIL results. The two retained signed projections agree on the bounded results. The existing hypotheses remain `0 <= num <= 999999999999` and `0 <= pos <= lim <= hp < 2^62`.

`Proof/NativeWordSub.v` unfolds the unchanged `X86Native3.execute` definitions for SUB and TEST, deriving the result, sign flag, register and memory frames, and SUB instruction-pointer update. The source/native value theorem requires explicit operand encoding and result bounds. It does not assume execution already equals the desired state. The two fixed SUB/TEST byte sequences decode in the retained decoder; these facts do not identify an emitted compiler image.

`Proof/AddressBridge.v` proves address encoding/decoding identities. It separately proves LA48 canonicality and readable access under additional low-address, region, and byte-memory premises. The closed theorem `RECORDCOUNT_numeric_contract_not_canonical` gives `num=0; pos=lim=hp=2^47`: the retained numeric contract holds while native canonicality is false. This is a theorem about the contract and is not a reported runtime defect. The original contract is unchanged.

The raw full v6 source, its exact 182-byte fragment, unchanged eight-instruction AST/map, original C2/CX4/Grok sources, successful raw compiler/kernel results, full MIT license, and source credits are included. `SOURCE-INPUTS.json` identifies 21 retained original inputs. `SELECTED-DECLARATIONS.json` lists all 36 new declarations. Complete non-elided types and assumptions are in `evidence/readable-types/logs/compile-readable-types.stdout.txt`; the all-module kernel context is in `evidence/readable-types/logs/kernel-all-modules.stderr.txt`. Original raw command paths remain in the successful receipts.

Run `python build-proof.py --check-only` to verify every payload row and the source-fragment identity. A fresh build uses `python build-proof.py --coqc PATH_TO_COQC --coqchk PATH_TO_COQCHK --output NEW_DIRECTORY`. It compiles all 23 included modules into the new directory and recursively kernel-checks all of them. The preserved extractor at `tools/retained-recordcount-extract-source.py` is the original generator, included as source-extraction evidence; the public builder consumes the unchanged retained AST rather than rewriting it.

The text-to-AST extraction remains trusted. Native operand loading/storing and variable layout, emitted template/image and fetched-step correspondence, JS decoding, physical readable/writable/executable regions, allocation capacity, stack behavior, the final FAIL handler, OS execution, complete judge, and caller contracts remain separate obligations. The actual interpreter negative-test excerpt is retained as `source/runtime-negative-fragment.asm`; the preserved native model supports TEST but lacks JS. No whole native process or complete-judge theorem is asserted.

This subset contains source and successful raw receipts only. Generated objects, failed development runs, private transport/configuration/transcripts, and local packaging helpers are excluded. The prior controller proof and every development artifact remain unchanged.

Pompetzki/Abschluss project, C2Link/Groebner, CX4, Grok Bot, and new Codex proof contributions are credited in `SOURCE-CREDIT.json`. The full existing project MIT `LICENSE` is included.
