The direct pmp compiler in this directory builds judge-v5.pmp, SHA256 4d936cb8103c6aa97fb6ec290f88b3ee636c69f94f0cdb089a4621d9ba251d1b. The compiler source pmpc-original.rkt includes its Windows kernel32 runtime. The separate linux-runtime.asm supplies the Linux syscall services. The builder retains the compiler's statement lowering while adapting startup and services for Linux.

From the source package root, run:

    python judge/native-v5/portable/build-native.py --source judge/judge-v5.pmp --output fresh-windows --target windows
    python3 judge/native-v5/portable/build-native.py --source judge/judge-v5.pmp --output fresh-linux --target linux

On Windows, --target all --wsl-exe wsl builds both using the configured WSL distribution. --wsl-distro selects a named installed distribution. Paths are converted with wslpath. No author drive or mount prefix is embedded in the builder. Python, Racket, NASM, MinGW-w64 GCC and import libraries, and GNU ld are external build tools. Compiler dependencies are the standard Racket libraries racket/string, racket/list, racket/file and racket/port.

Every output directory must be new. Each build writes the assembly, object files, binaries, command logs, exit codes, hashes, and a build receipt. The source and compiler hashes are checked before lowering. The native checker takes one JDG pathname argument.

V5 accepts decimal integers from 0 through 999999999999, including arbitrary insignificant leading zeros. The significant count stays zero while zero digits are read before the first nonzero digit. The 13th significant digit is rejected before multiplication or addition. Registry entries still must equal an initial prefix of the embedded canonical REG0.

The v5 checks completed 254 cases on each native platform: 94 downloaded bot certificate cases, 42 additional numeric and authentication fixtures, 117 released math cases, and the complete 4,551-theorem replay. All expected verdicts and exits passed. A separate 136-case Windows interpreted run and 254-case Racket run also passed. The run receipt records the omitted interpreted full replay and math batch through its per-platform counts.

The basic native runtime uses fixed 8-byte variable cells and static literal bytes. It does not provide the later runtime's triple-copy/string-integrity checks. Source-to-native and executable-to-Gallina correspondence remain open. The new decimal-model proof establishes the stated arithmetic properties in Gallina; it does not establish executable token parsing or generated byte correspondence.
