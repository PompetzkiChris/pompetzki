# Pompetzki

Pompetzki is an exact mathematics language and a collection of proof replay tools, certificates, and formal verification sources by Christopher Pompetzki.

This repository is being prepared for the public release. Release packages and the corresponding source snapshot will be added after their final validation. Each published package will include its scope, validation receipts, and SHA-256 checksums.
